## Owner decision on synthetic software verification (added GOV-D040-RULE-S, 2026-10-24)

| ID | Date | Decision | Status | Rationale | Approved by / date |

| D-040 | 2026-10-24 (GOV-D040-RULE-S) | **Rule S — Synthetic-only software verification.** **(1) Purpose.** Synthetic-only software verification checks whether F-A software meets its stated specification for: clinical-anchor offset handling throughout boosting, prediction consistency, validation offsets and early stopping, sample-weight handling, model persistence and reload, reproducibility, and attribution behaviour. **(2) Data.** Only entirely artificial data, generated by documented code with fixed, recorded random seeds.
